# Task10front

DermAI — AI-driven multimodal dermatological screening for scalp, hair and nail preliminary assessment.

## Stack

- Next.js (App Router) + TypeScript
- better-sqlite3 (local SQLite storage)
- Demo/prototype AI screening engine

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes

- Demo/prototype AI engine — educational screening only, never a diagnosis.
